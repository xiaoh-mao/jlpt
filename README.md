# JLPT 模考

桌面刷题工具，题目来自官方《日本語能力試験公式問題集》
（2012 年版和 2018 年第二集），N1–N5 每级两套，共 10 套。
卷子是原版页面，听力是原版录音，正确答案来自官方正答表。
姊妹项目：[TOPIK 模考](https://github.com/xiaoh-mao/topik)（界面和用法一样）。

## 下载

- 只支持 **Windows 10 / 11**，用系统自带的 Edge 和 PowerShell，不用装别的。
- GitHub 页面上点 **Code → Download ZIP**。解压**之前**先右键 zip → 属性 → 勾「解除锁定」→ 确定，
  不然每次启动 Windows 都会弹安全警告。也可以 `git clone`。卷子页面图和录音都在仓库里，约 370 MB。

## 怎么用

1. 双击 **`JLPT模考.bat`**，会弹出一个独立窗口（Edge 应用模式）。
   想要带图标的桌面快捷方式，就在这个文件夹里运行
   `powershell -ExecutionPolicy Bypass -File scratch\make-ico.ps1 -Shortcut`。
2. 在首页右上角选级别（N1–N5），选一套卷子，点「整套模考」，
   或者点某一部分做分项练习。
3. 窗口关了进度也还在：没交卷的那场回首页点「继续」就能接着做，
   剩余时间、录音播到哪里、卷子和答题卡各翻到哪里都会保存。

换电脑时把 `data\` 文件夹拷过去，做题记录和错题本就都带走了。

## 界面分区

**首页**
- 左边：这一级的满分、合格线、模考时间；下面每套卷子一行：
  文字・語彙 / 文法 / 読解 / 聴解 分项练习（带上次整科做完的正确率）、
  模考最好成绩、「整套模考」。
- 右边：错题本（有多少道待重做）、最近记录。
- 右上角：「＋ 导入自备试卷」。

**做题页**（左卷右卡）
- 左边是**卷子**：顶部标签切换 文字・語彙 / 文法 / 読解 / 聴解 /
  听力原文 / 正答表（听力原文在练习时对过听力答案后出现，订正时都有）。
- 右边是**答题卡**：按大题分组，点圈作答，⚑ 标记待检查的题。
  订正时可勾「只看错题」。
- 听力的播放条在答题卡顶上：每个問題一个按钮，暂停、拖动、±5 秒、变速，
  一段放完自动接下一段。模考和练习都一样。

**成绩页**：总分估算（0–180）、各得点区分和基准点、每个大题的正确率；
可以「对照卷子订正」「再做一遍」「去错题本」。

**错题本**：每道题按最后一次的结果收录，
可以一次重做一套卷子里的全部错题，懂了的手动「移出」。

## 主要功能

- **点题号跳转**：点答题卡上的题号，卷子自动滚到那一题；
  听力题的**录音也会跳到那一题开头**。
  录音播到哪题，答题卡上就标 ♪；勾选「卷子跟着走」，卷子也会跟着录音翻过去。
  （听力 問題3 往后卷子上没有逐题内容，只能定位到大题。）
- **听力原文 + 中文译文**：「听力原文」标签页显示官方原文，
  每题讲完的地方插一张中文译文卡，标签栏右侧「译文」开关可以隐藏。
  译文是 Claude 照原文翻的，不是官方版本。练习时对过这一大题的答案才显示，
  订正时随时能看，模考时不显示。
- **模考**：按真实考试的科目顺序和时限计时，时间到自动交卷；
  聴解那一节不限时，做完自己交。
  结束后按正确率估算分数和是否合格（真考试是等化计分，仅供参考）。
- **分项练习**：只做某一部分，每个大题做完可以单独「对答案」。
- **订正**：交卷后回到卷子，对错、正答表、听力原文都能对照着看。
- **快捷键**：`1`–`4` 作答并跳下一题，`↑` `↓` 换题，`F` 标记，
  `0` 清除；听力时 `空格` 播放/暂停，`←` `→` 快退/快进 5 秒。
- **导入自备试卷**：在 `papers\自备\` 下建一个文件夹，放入 PDF 和 MP3，
  再到首页「导入自备试卷」里设置级别、文件和答案。
  自备卷用 PDF 原样显示，不支持点题号跳转。

## 目录

| 路径 | 内容 |
|---|---|
| `JLPT模考.bat` | 启动入口 |
| `app/` | 界面（纯前端，零依赖）；`core.*` 和 TOPIK 模考共用，`exam.*` 是 JLPT 自己的 |
| `lib/` | 本地小服务（PowerShell）和启动脚本；`exam.ps1` 是 JLPT 自己的 |
| `papers/` | 官方卷的页面图和录音；`自备/` 放自己的卷子。原版 PDF 做题用不上，不在仓库里 |
| `data/` | 做题记录和没交卷的进度（第一次运行时自动建） |
| `scratch/` | 生成题目数据的脚本（下载、渲染、抄答案、定位、译文），用法写在各文件开头；做题用不上，要什么工具见 `CLAUDE.md` |
